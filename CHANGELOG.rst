===========================
microsoft.wsl Release Notes
===========================

.. contents:: Topics

v1.0.0
======

Minor Changes
-------------

- command - add module to run a command in a WSL distribution
- distribution - add module to manage WSL distributions
- distribution_config - add module to manage a WSL distribution's configuration
- distribution_config_info - add module to get the wsl.conf configuration for WSL distributions
- distribution_info - add module to get detailed information about WSL distributions
- export - add module to export a WSL distribution
- import - add module to import a WSL distribution
- status_info - add module to get the status and version of WSL distributions

New Modules
-----------

- microsoft.wsl.command - Run a command in a WSL distribution.
- microsoft.wsl.distribution - Manage WSL distributions.
- microsoft.wsl.distribution_config - Manage a WSL distribution's configuration.
- microsoft.wsl.distribution_config_info - Get the wsl.conf configuration for WSL distributions.
- microsoft.wsl.distribution_info - Get detailed information about WSL distributions.
- microsoft.wsl.export - Export a WSL distribution.
- microsoft.wsl.import - Import a WSL distribution.
- microsoft.wsl.status_info - Get the status and version of WSL and any distributions.

## v1\.0\.0

<a id="minor-changes"></a>
### Minor Changes

* command \- add module to run a command in a WSL distribution
* distribution \- add module to manage WSL distributions
* distribution\_config \- add module to manage a WSL distribution\'s configuration
* distribution\_config\_info \- add module to get the wsl\.conf configuration for WSL distributions
* distribution\_info \- add module to get detailed information about WSL distributions
* export \- add module to export a WSL distribution
* import \- add module to import a WSL distribution
* status\_info \- add module to get the status and version of WSL distributions

<a id="new-modules"></a>
### New Modules

* microsoft\.wsl\.command \- Run a command in a WSL distribution\.
* microsoft\.wsl\.distribution \- Manage WSL distributions\.
* microsoft\.wsl\.distribution\_config \- Manage a WSL distribution\'s configuration\.
* microsoft\.wsl\.distribution\_config\_info \- Get the wsl\.conf configuration for WSL distributions\.
* microsoft\.wsl\.distribution\_info \- Get detailed information about WSL distributions\.
* microsoft\.wsl\.export \- Export a WSL distribution\.
* microsoft\.wsl\.import \- Import a WSL distribution\.
* microsoft\.wsl\.status\_info \- Get the status and version of WSL and any distributions\.
